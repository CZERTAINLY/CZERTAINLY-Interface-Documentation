Stateless v3 certificate operations by utilizing attributes in request for identifying authority or RA profile

Revoke certificate

Revoke a certificate (sync 204 or async 202)

Authorizations:
ConnectorAPIKeyAuthCertificateTLSAuthNoAuthBasicAuth
Request Body schema: application/json
required
required
Array of objects (RequestAttribute)

Authority attributes

required
Array of objects (RequestAttribute)

RA profile attributes

certificate
required
string <byte> non-empty

Base64 of cert to revoke. Serial + issuer DN parsed from this constitute the cert identity at the CA.

reason
required
string (CertificateRevocationReason)
Enum: "unspecified" "keyCompromise" "cACompromise" "affiliationChanged" "superseded" "cessationOfOperation" "certificateHold" "privilegeWithdrawn" "aACompromise"

Revocation reason

Array of objects (RequestAttribute)

Revoke-specific dynamic attributes

Array of MetadataAttributeV2 (object) or MetadataAttributeV3 (object) (MetadataAttribute)

Optional connector-defined metadata. Populated when Core has the original issue meta. CAs that revoke purely by serial+issuer ignore it; CAs that track revocation via an upstream handle (e.g. DigiCert order ID) consume it.

Renew certificate

Renew a certificate (sync 200 or async 202)

Authorizations:
ConnectorAPIKeyAuthCertificateTLSAuthNoAuthBasicAuth
Request Body schema: application/json
required
required
Array of objects (RequestAttribute)

Authority attributes

required
Array of objects (RequestAttribute)

RA profile attributes

request
string <byte>

Certificate signing request, Base64-encoded. Optional when reuseKey=true.

format
string (CertificateRequestFormat)
Default: "pkcs10"
Enum: "pkcs10" "crmf"

CSR format

existingCertificate
required
string <byte> non-empty

Base64 of cert to renew. Serial + issuer DN parsed from this constitute the cert identity at the CA.

reuseKey
boolean
Default: false

When true, request (CSR) is optional. Proof-of-possession is delegated to the upstream CA's renewal policy.

Array of objects (RequestAttribute)

Renew-specific dynamic attributes (schema from shared /issue/attributes endpoint)

Array of MetadataAttributeV2 (object) or MetadataAttributeV3 (object) (MetadataAttribute)

Optional connector-defined metadata returned by the original issue/renew/register response. Replayed here so a stateless connector can resolve the upstream end-entity without an extra lookup.

Register certificate

Pre-register a certificate's identity at the upstream CA (no CSR)

Authorizations:
ConnectorAPIKeyAuthCertificateTLSAuthNoAuthBasicAuth
Request Body schema: application/json
required
required
Array of objects (RequestAttribute)

Authority attributes

required
Array of objects (RequestAttribute)

RA profile attributes

subjectDn
string

Subject DN. Optional per RFC 5280 §4.1.2.6: an empty subject is permitted when subject naming information is carried entirely in the Subject Alternative Name extension (which the connector MUST then mark critical at issuance). At least one of subjectDn or subjectAltName must be non-empty.

subjectAltName
string

Subject Alternative Name in OpenSSL convention textual form (e.g. DNS:foo,IP:1.2.3.4,email:x@y). SAN MUST be carried here ONLY — do not duplicate it as OID 2.5.29.17 in extensions[]. Connectors reject duplicate-source requests with VALIDATION_FAILED. Required when subjectDn is empty (see RFC 5280 §4.1.2.6).

Array of objects (CertificateExtension)

Structured certificate extensions (OID + critical + base64 value). All extensions OTHER than SAN go here.

Array of objects (RequestAttribute)

Register-specific dynamic attributes
